# Squadron Logistics — Proof of Concept

A squadron inventory tracking proof of concept. **Demo data only.**

- Inventory, checkouts/returns, incoming supplies, reporting, and user-role demonstrations.
- The static site is not an authenticated CAP information system.
- Do **not** enter real CAP equipment assignments or member details on a public site.
- A private Google Sheets demo backend has been created separately under the business Google account. A secure, approved Apps Script deployment is still required before live multiuser use.

Deploying the demo on GitHub Pages requires repository Pages eligibility and configuration. A private repo on a free personal GitHub plan generally cannot publish GitHub Pages without making the repository public.
